  javnimi `RoleEvent` podtipi. Podedovana Forge `Event` pogodba vključi cancellation.
  Vsi javni deklarirani člani (ter protected `NpcScript.log`) in generic podpisi so navedeni.
  Podedovani člani se sledijo prek superclass/interface povezav. Drugi referencirani tipi so
  izrecno zunanji, ne samodejna širitev v1. Obstoječi podpisi z item/block/quest/dialog/faction
  tipi se ne prikrijejo; novih handlerjev ni. Player/world razširitev ostane M6.11 (Q92).
- **Q178 — manjkajoči opisi/imena:** binarni API nima izvornega Javadoca in zanesljivih imen
  parametrov. Generator odsotnost opisa izrecno označi, parametre označi po položaju `argN`;
  ne izmišlja semantike, frekvenc, nullability ali imen. JSON objavi to omejitev in izključitve.
- **Q179 — sprejem brez runtime spremembe:** samo novi controller `m69-api-v1`; ne ponavljamo
  zelenih unit/build/package/M6 runtime serij (Q90). Novi sourceSet ni del moda. Harness primerja
  popolnost z neodvisnim reflection popisom, generične tipe, mutabilnost, dedovanje, JSON/MD
  skladnost, obrnjeno odkrivanje in dva JVM izhoda bajt za bajtom. Prevede vseh 16 objavljenih
  primerov ter zahteva diagnostiko napačnega event tipa. Skript ne izvaja; Minecraft/Forge ne zaganja.
  Pregledajo se tudi LF/UTF-8 in nespremenjeni produkcijski vhodi/zapakirani mod.
