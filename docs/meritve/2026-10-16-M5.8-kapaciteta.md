# M5.8 — kapaciteta proti baselineu: potrditve K3 (16. 10. 2026)

Obseg po **Q27** (skrajšan): (a) potrdi samo N tik pod pragom p95 ≤ 25 ms, (b) meja 50 ms iz
[lestvice](2026-10-15-M5.8-lestvica.md), (c) okno 60 + 180 s. Zaganjalnik `audit/m58-skrajsano.ps1`,
serije `ponovitve-run.ps1` (3 ponovitve, svež svet), vse T1–T6 zelene. O = original, S = vsa sprejeta stikala.

## Rezultati pri 25 ms (MSPT p95, ms)

| celica | ponovitve | mediana | razpon | izid |
|---|---|---|---|---|
| S-boj 1500 | 22,02 / 22,54 / 22,02 | 22,02 | 2,4 % | ≤ 25 ✔ |
| O-boj 1000 | 22,54 / 22,54 / 23,07 | 22,54 | 2,3 % | ≤ 25 ✔ |
| S-ned 700 | 22,54 / 21,50 / 20,97 | 21,50 | 7,3 % | ≤ 25 ✔ |
| O-ned 500 | 23,07 / 22,54 / 22,54 | 22,54 | 2,3 % | ≤ 25 ✔ |

Idle je bil potrjen 15. 10. po polnem protokolu (120 + 300 s, oba N para, ločena razpona):
O 350 (20,97) / S 3500 (24,64).

## Kapaciteta pri p95 ≤ 25 ms (izhodni kriterij)

| varianta | original | stikala | razmerje | potrditev |
|---|---|---|---|---|
| idle | 350 | 3500 | **10×** | polna (par, ločena razpona) |
| boj | 1000 | 1500 | **1,5×** | skrajšana (spodnji N) |
| nedosegljiva | 500 | 700 | **1,4×** | skrajšana (spodnji N) |

Meja 50 ms (iz lestvice, nepotrjena): idle O 500–600 / S 7000–8000, boj O 1500–2000 / S 2500–3000,
nedosegljiva O 800–1000 / S 1200–1400.

## Omejitve

- Pri boju in nedosegljivi je potrjena samo spodnja meja razpona (N pod pragom drži), ne pa da
  zgornji N iz lestvice prag preseže s tremi ponovitvami.
- Krajše okno (60 + 180 s); razponi 2–7 % so primerljivi s polnim oknom pri idle (2–12 %).
- `-Razprseno` (redek razpored) ni pognan.
