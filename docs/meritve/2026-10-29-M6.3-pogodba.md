# M6.3 — tipizirana script pogodba (`NpcScript`)

2026-10-29 · seja 172 · **zaključen, poskus 1**. Vhodni commit `c42c906`.
Teste, build in Minecraft zaganja controller.

## Izvedba in meje

- `rework/script/NpcScript` (abstrakten, izbiren osnovni razred Java taba): ena javna no-op metoda
  za vsak od 16 NPC hookov iz `ScriptHooks.npc()`, z istim event tipom, kot ga poda `EventHooks`.
  `@Override` pusti javacu, da zavrne napačno ime ali tip eventa. `log(Object)` = JS `log`: konzola
  tekočega taba (`ScriptContainer.Current`) + `LogWriter.info`.
- API so obstoječi vmesniki `noppes.npcs.api` (`event.npc` je `ICustomNpc`, `event.API`); nič ni
  kopirano, noben star razred/podpis ni spremenjen. Navaden javni razred s hook metodami (M6.2) ostane veljaven.
- `JavaHookBinder`: hoja po nadrazredih se ustavi pri `NpcScript`, zato se vežejo in kličejo samo
  prepisane metode; no-op privzete metode se nikoli ne izvedejo (enaka semantika »manjkajočega« hooka).
- Ni še: player/world dostopi (M6.11), cache/atomski reload (M6.4), source map vključitev (M6.5).

## Odločitve

**Q148 — oblika pogodbe:** abstrakten osnovni razred z no-op hooki + `log`, ne vmesnik in ne novi
`IRw*` ovoji. Razlog: Java 8 default metode bi tudi šle, a razred omogoča `protected final log`
brez dodatnega stanja; `@Override` da napako prevajalnika namesto runtime; obstoječi API ostane edini.
**Q149 — dokaz:** unit/build/package + en Forge ID samo v zapakiranem načinu. Razlog: to je
produkcijski runtime; enakost dev/packaged poti je dokazal M6.2, dodatni dev zagon bi bil ponovitev (Q90/Q92).
**Q150 — »stari podpisi nespremenjeni«:** dokazano z verify-package (dodana samo nova razreda, noben
original API razred spremenjen) in z nespremenjeno sledjo navadnega M6.2 razreda v istem zagonu.
