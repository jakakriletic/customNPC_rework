**Stanje: zaključeno, poskus 1 (Q176).**

**Zaupanje pomeni dovoljenje za izvajanje kode s pravicami procesa Minecraft.**
Loader, omejen bytecode cache, typed API, whitelist ali pregled bytecode ne zagotavljajo
izolacije datotek, omrežja, refleksije, procesov, CPU ali heap. Napaka v zaupanem hooku
lahko ustavi strežniško nit; varnega prisilnega timeouta ni. Neznanega AI izhoda ne
izvajamo neposredno. Upravljalec najprej pregleda glavni source, vključitve, statične
inicializatorje in konstruktorje; clone/import/world ter lokalni pisci datotek morajo biti
prav tako zaupanja vredni. Odvzem pravice urejanja ne ustavi že shranjenega programa;
za ustavitev upravljalec izklopi handler oziroma `EnableScripting`.

`compileScripts` je compile-only, z `-proc:none`, brez nalaganja/izvajanja skript;
ni splošna izolirana storitev za sovražne compiler vhode ali nezaupan classpath/procesorje.
Runtime Java razrede inicializira in izvaja. Pravic ne preverja za vsak hook: odobrena
shranjena koda teče ob dogodkih brez prisotnega avtorja, kakor JS. Lokalni filesystem in
compiler/API classpath sta odgovornost upravljalca. Samodejni Java jezik/classpath,
GUI/clone/restart in prehodi ostanejo M6.12; M6.8 jih ne nadomešča.

## Preverjeni robovi v kodi [K]

- `PacketHandlerServer.onServerPacket`: `OpsOnly`/op pred razpošiljanjem; na server niti
  permission in orodje pred zasebnim `handlePacket` in `Server.readNBT`. `ScriptDataSave`
  naloži isti NBT (`ScriptLanguage`, `ScriptEnabled`, inline source in `ScriptList`),
  nastavi `updateAI=true`, `lastInited=-1`. Ni ločenega Java upload omrežnega endpointa.
  Lokalnih datotek scenarij ne predstavlja kot oddaljen upload.
- Originalna `CustomNpcsPermissions` in `EnumPacketServer`: ista scripter pravica,
  originalni default ALL in bypass. Preverjeno z branjem in lokalnim `javap` originalnega
  mapped jarja (brez build/test zagona).
- Originalni `CommandNoppes` → `CommandNoppesBase.executeSub` → `CmdScript.reload`:
  `sender.canUseCommand(4, "commands.noppes.script.reload")` pred reloadom; glavni ukaz
  zahteva level 2. Scripter pravica sama ne podeli ukaza reload. Reload tudi briše world
  tempdata/naloži druge script handlerje; test je izključno v zavržnem svetu.
- `JavaNpcScripts`/`ScriptContainer`: `EnableScripting` ustavi izvajanje, loader ni
  security policy; nobenega globalnega SecurityManagerja ali prisilnega Thread.stop.
- Forge 14.23.5.2847 `PermissionAPI`/`IPermissionHandler` in event konstruktorji preverjeni
  z lokalnim `javap`. Test vrne prejšnji provider, config in source map v finally.

## Merila in zahtevani controller testi

`java-hooks-run.ps1 -Mode packaged -Package m68` ustvari svež zavržen server iz istega
zaklenjenega okolja kot M6.2–7. Ohranjen scenarijski lock, zaščiteni SHA vhodi, brez
sočasne Jave. Novi ID `m68-packaged-v1`, poleg `unit`, `build`, `package`.
Produkcija in stari scenariji se niso spremenili, zato m61–m67 serij ne ponavljamo (Q90).
En funkcionalni zagon z 27 trditvami; `elapsedNanos` je čas celotne sonde kot podatek,
ne strošek hooka, MSPT ali primerjava hitrosti jezikov. Ni nove produkcijske funkcije,
privzetega stikala ali optimizacije, zato ni nove cenovne meritve/gate.

Za vsak JS/Java payload: OpsOnly zavrne non-op tudi s grantom; eksplicitni deny
zavrne source/vključitve/jezik/enable tudi z orodjem; odsotno orodje zavrne grant;
zaupan scripter save zamenja handler in hook teče; kasnejši deny ne sme zamenjati ali
izklopiti veljavnega handlerja. Primerjava celotnega NBT, updateAI, lastInited in
napredka branja payload prepreči lažen PASS samo zaradi napačne serializacije.
Ukazni manager non-op reload zavrne (exit rezultat 0, token/source sentinel ista),
op pa ga sprejme (1, nov token, sentinel izgine); shranjena Java nato teče.
Marker mora prej manjkati, po izvedbi vsebovati dejansko verzijo JVM, SecurityManager
ostane isti. Provider/config se obnovita. PowerShell ločeno pripne 27/27 in ključne izide.
