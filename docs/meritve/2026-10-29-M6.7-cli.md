## Uporaba

Privzeti vhod je `scripts/java/scripts.json` (avtor ga ustvari za svoje skripte), poročilo
`dev/build/reports/scripts/compile.json`. Primer manifesta:

```json
{"schema":1,"tabs":[{"id":"1","files":["MyNpc.java","shared/Helper.java"]}]}
```

```powershell
.\dev.ps1 compileScripts --offline
.\dev.ps1 compileScripts --offline -PscriptsManifest=C:/scripts/scripts.json -PscriptsReport=C:/scripts/result.json
```

Gradle relativne `-P` poti razreši od `dev/`; poti datotek v manifestu od mape manifesta.
Privzeti compiler classpath je trenutni patch output + mapped compile odvisnosti, enako
kot plain JUnit API. `-PscriptsClasspathFile=C:/scripts/classpath.txt` izbere ekspliciten
classpath za drugo okolje (enaka vsebina kot `RwJavaClasspath` datoteka); orodje ga ne
ugiba ali spreminja configa sveta. JDK 8 ostane zahteva; brez providerja `compiler.unavailable`.
Mapped CLI dokaz sam ne dokazuje SRG/Forge runtime povezave. Izpisani `inputFingerprint`
je isti algoritem kot runtime, enakost je smiselna samo pri enakih vhodih/classpathu.

Poročilo `schema=1`, `operation=compile-only`, skupni `success`, `compiler`, `elapsedNanos`,
vhodne poti, splošne napake in urejeni rezultati tabov (`main`, `inputFingerprint`,
`success`, `classes`, `compilerOutput`, `elapsedNanos`, `problems`). Napaka ima `kind`,
`code`, dejansko vhodno `file`, `origin`, `line`, `column`, `message`; neznani koordinati -1.
Manjkajoč/pokvarjen/prazen manifest pade; napake posameznega taba ne skrijejo drugih tabov.
CLI exit 0 samo ob uspehu vseh tabov, 1 ob vhodni/prevajalni napaki, 2 ob napačnih argumentih
ali neuspešnem pisanju poročila. Gradle/dev.ps1 neuspeh propagirata kot neuspešen ukaz.
Poročilo ne sme prepisati manifesta ali izvorov, tudi ne prek obstoječe povezave.
Bytecode ostane v pomnilniku, nič se ne namesti v svet ali izvaja. UTF-8 BOM je sprejet.
Pravilo javnega imena enote je ohranjeno iz M6.2 (preskoči komentarje, ni popoln Java parser).

## Korpus in nespremenjena merila

`dev/testworld/java-cli/`, kopija v `dev/build/m67/corpus <čas>` (poti s presledkom):

- **valid:** dva ločena taba z istim typed `Main` + `Helper` + `Tripwire` in tretji plain
  `Plain` + `Tripwire`. API `NpcEvent`/`ICustomNpc`, `NpcScript`, lambda, preklic dogodka.
- **invalid:** napaka generika v vključitvi `BrokenHelper.java:5`, napačen `@Override`
  `Wrong.java:3`, sintaksa `Syntax.java:3`. Vsak tab mora pasti, brez delnega bytecode;
  diagnostika mora imeti navedeno datoteko, vrstico, pozitiven stolpec in compiler code.
- Registriran pravi `TripwireProcessor` na compiler classpathu; procesor in skriptni
  static inicializatorji/konstruktor pišejo marker ob izvedbi. Marker ne sme nastati.
- Controller scenarij zahteva exit 0/1, vse tri rezultate, prave odtise, odsotnost script
  class datotek na disku, odsotnost Minecraft procesa/bootstrapa in nespremenjene fixture.
- Devet novih JUnit testov: API/generiki/vključitve, isti compiler izid/odtis, izolacija
  tabov, vhodne napake, skupne source napake, odsoten provider, procesor in BOM/presledki.

`java-cli-run.ps1` meri en `dev.ps1 compileScripts` na korpus, z obstoječim controller
buildom; ne ponavlja serij. Čas `commandMillis` vključuje PowerShell/Gradle/JVM startup,
`compileNanos` pa branje/validacijo/prevajanje poročila. Cilj »nekaj sekund« se ovrednoti
na teh dveh dejanskih časih, ne samo na času javac. Controller lastnik zagonov in zaklepa.
