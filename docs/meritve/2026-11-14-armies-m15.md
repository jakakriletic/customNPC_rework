# Army GUI in M15 — 14. 11. 2026

**Army GUI.** NPC wand → Global → Armies uporabi isti register in iste pravice kot ukaz.
Ustvarjalec je lastnik. Obstoječa AI → Army... izbira že omogoča dodelitev s seznama.
`army-gui-run.ps1` (`m118a-gui-2026-11-14-143607`, 104 preverjanja PASS): ustvarjanje, viden
vnos, vrnitev v Global, preizkus palice in pravic, shranjevanje čez restart in skrit gumb pri `RwArmies=0`.

**M15.** `creature-run.ps1` na Forge dev dedicated strežniku z dvema ločenima klientoma brez map
bitij (`m15-creature-2026-11-14-143357`, PASS). Epic Troll uporablja vgrajen model z novimi klipi in JS dogodkom, Copper Beetle prinese
model, PNG in klon z 37 HP. Napačen JSON je zavrnil reload, prejšnji klip je ostal dostopen.
Oba klienta sta videla nov klip; drugi je videl tudi NPC-ja iz sveže kopiranega paketa
po `/rwcreature deploy`. Model se je odstranil prek Display GUI-ja. NPC-ji in klipi so
ostali po restartu, novi klient brez datotek je dobil aktualne podatke.

**Meje.** Preizkus je funkcionalen na dev strežniku; cena v velikem svetu in produkcijski
modpack ostajata neizmerjena. Skripta bitja se uporabi ob postavitvi, reload osveži modele in klipe.

**Pregled ukazov.** Izbira modela sodi v Display, ker je nastavitev posameznega NPC-ja.
Naslednja koristna gumba bi bila predogled klipa v istem meniju in postavitev paketa v Server Clones.
Odstranitev vojske bi sodila v Armies s potrditvijo, ker vpliva na člane in pravice. Palica že
pokriva dodelitev, premike in pravice; Linked NPCs pokriva kategorije in undo. Reload, meritve
in ukazi, ki spreminjajo nastavitve celotnega strežnika, ostanejo skrbniška opravila.
