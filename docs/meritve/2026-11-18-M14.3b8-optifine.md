(unit, build, package, `m143b-optifine-none-v4`, `m143b-optifine-bsl-v4`). Izhodišče `3432139`.

Stikalo ostane `RwNpcInstancing=0`.

## Odločitve

**Q533 (18. 11., samostojno):** paket ni zunanje blokiran. Lastnikov
`OptiFine_1.12.2_HD_U_G5.jar` (SHA256 `3B000679…BA271E`) je v CurseForge instancah

klientskega coremoda v zapakiranem klientu.

**Q535 (18. 11., samostojno):** dva primera — OptiFine brez shader paketa in z BSL v7.1.04
(SHA256 `03C6E5CC…19B83`, kopija iz Giga Advantura). Snooper in OptiFine capes izklopljeni;
preverjanje različice OptiFine ostane kot pri lastnikovi igri.

## Pogodba

`npc-batch-optifine-run.ps1 -Shader none|bsl` + `NpcBatchCompatHarness optifine=1`:
OptiFine in stanje shaderja dejansko naložena; pri `RwNpcInstancing=1` se batch program
nikoli ne zgradi (vrata `program`); A/B/A2 FBO slike in GL stanje bitno originalni pred in
po živem oknu; živi svet pri 0 in 1 riše samo original, 0 GL napak v oknu; obnova GL stanja
harnessa brez napake; dnevnik brez linkage/render/OpenGL napak; vsi vhodi nespremenjeni.

## Zavrnjeni poskusi (napake harnessa)

- **v1-none (Q536):** `Unable to find type [IO.Compression.ZipFile]` pred zagonom klienta;
  skripta zdaj naloži `System.IO.Compression.FileSystem` (kot druge skripte).
- **v2-bsl (Q537):** `summon` zavrnjen („out of the world”): chunk (0,0) ni bil naložen,
  ker je ravni spawn pri ~(744,−227); v2-none je uspel le po času. Harness chunk naloži prej.
- **v3-bsl (Q538):** GL 1282 v dnevniku iz harnessa — `glPopAttrib` je obnovil draw buffers
  (`COLOR_ATTACHMENT0..n` shader FBO) na FBO 0. Dokaz sam je bil uspešen (živo okno 0 napak,
  0 batch izrisov in programov). Harness zdaj pred `glPopAttrib` veže vhodni FBO in obnovo
  preveri z `glGetError` (`optifine-restore-gl`, `-after-live`); preverba dnevnika ostane.
  Ker sprememba spremeni vhode obeh primerov, tudi none ponovljen kot v4.
