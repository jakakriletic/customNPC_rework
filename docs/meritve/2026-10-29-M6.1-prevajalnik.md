## Izvedba in meje

`rework/script/JdkScriptCompiler` uporablja JavaCompiler, Java 8, UTF-8, `-g`,
`-proc:none`, brez implicitnih source datotek; rezultat so bajti in strukturirani
file/line/column/code/message. Ob neuspehu ni delnih bajtov; brez ponudnika jasen
`compiler.unavailable`. Prevajanje ne nalaga/inicializira skriptnih razredov.
Vsak izrecen `newLoader` ima game API parent; to ni sandbox ali končni cache/reload M6.4.

`JavaCompilerProbe` se kliče samo iz izrecne skripte v začasnem testnem svetu.
Ni registracije jezika ali nove poti v handlerjih, ni prenosa originalnih razredov,
ni sprememb NBT/GUI, originalnega JAR ali `environment-lock.json`. Privzeto ostane JS.
M6.2–M6.12 še niso implementirani; ta paket ne dokazuje njihovih kriterijev.
