# M6.2 — popis hookov in Java adapter na robu NPC handlerja

2026-10-29 · seja 171 · **zaključen, poskus 2 (harness)**. Vhodni commit `067b1ba`;
baseline prenos `DataScript` ločen commit `cf498ae` (D-003, `DataScriptBaselineTest` v obeh
`testOriginal` in `test`). Teste, build in Minecraft zaganja controller.

## Izvedba in meje

- `rework/script/hooks/ScriptHooks`: determinističen popis 16 NPC hookov (ime = `EnumScriptType.function`,
  statični event tip, kot ga poda `EventHooks`; vrstni red enuma). String hooki zunaj enuma: isto
  pravilo imena kot `EventHooks.onForgeEvent` (`forgeHookName`). Izključeno iz Java v1 (Q92):
  player, block, door, item, projectile, forge — njihove JS poti ostanejo originalne.
- `JavaHookBinder`: javna metoda z imenom hooka mora biti `public`, ne-static, z enim parametrom,
  ki sprejme event tip; sicer napaka `hook.signature`/`hook.ambiguous`, nikoli tih »manjkajoč« hook.
  Ostale metode (pomožne) se ignorirajo.
- `JavaNpcScripts` + `DataScript`: `ScriptLanguage=Java` (obstoječi NBT ključ) teče skozi iste tabe
  v istem vrstnem redu, z isto instanco eventa; init ob reloadu, `EventHooks` in bus post ostanejo
  nespremenjeni okoli. Vsak tab: lasten loader (parent = API loader), instanca na generacijo
  (`ScriptController.lastLoaded`) ali ob spremembi izvora. Isti monitor in `ScriptContainer.Current`
  kot JS (Q143). Napake (prevod, podpis, izjema) → `errored`, konzola taba s file:line:column/stack,
  `NotifyOPs` kot original. Vsi drugi jeziki gredo po originalni zanki.
- Config `RwJavaClasspath` (privzeto prazno): datoteka ali classpath za prevajalnik (Q144).
- Ni še: bytecode cache in atomski reload (M6.4), typed osnovni razred/`log` (M6.3), source map
  vključitev (M6.5), GUI izbira jezika (M6.12), varnostna politika (M6.8). Java = zaupanja vreden avtor.

## Odločitve

**Q142 — rob:** Java veja v `DataScript.runScript` (handler), ne v `ScriptContainer`. Razlog: en
prenesen razred (131 vrstic) namesto JS containerja z monitorjem; JS pot ostane bitno originalna.
**Q143 — context:** Java tab uporablja isti internirani monitor `"lock"` in nastavi/počisti
`ScriptContainer.Current` kot original. Razlog: binarni porabniki (chest/projectile) in brez
sočasnega JS/Java; gnezdenje ostaja M6.6 (samo po reprodukciji).
**Q144 — classpath:** eksplicitni config `RwJavaClasspath` (datoteka ali niz), prazno = jasna napaka.
Razlog: M6.1 je pokazal, da `java.class.path`/mapped jar ne zadoščata (Q133); samodejna distribucija M6.7/M6.12.
**Q145 — enota:** inline koda taba in vsaka vključitev sta ločeni prevajalni enoti; glavni razred je
javni tip prve enote (komentarji preskočeni). Razlog: Java ne dovoljuje lepljenja kot JS.
**Q146 — dokaz:** dva controller ID-ja (dev, packaged) + unit/build/package; m61-* se ne ponavljajo (Q90).

## Rezultati

Poskus 1 (`c7d8bd67…`): unit, build, package in `m62-dev-v1` PASS. `m62-packaged-v1` FAIL 11/14:
oba Java taba `compiler.err.cant.access … fml.common.eventhandler.Event` (`e.setCanceled`), zato
`java-equals-js`, `java-tabs-not-errored`, `java-reload-equals-js` ne. Vzrok v harnessu: zapakirani
compiler classpath (`srgBin`) nima FML eventhandler razredov; runtime jih jemlje iz Forge universal.
**Q147 — poskus 2:** harness doda pripeti Forge universal jar na compiler classpath (s trditvijo, da
vsebuje `Event`); produkcija nespremenjena, dev/unit/build/package se ne ponavljajo (Q90), nov ID
`m62-packaged-v2`. Posledica za uporabnike: `RwJavaClasspath` v modpacku mora vsebovati tudi Forge
universal (samodejno M6.7/M6.12).

Poskus 2 (`d4972147…`, produkcija ista kot `c7d8bd67…`): `m62-packaged-v2` PASS 14/14
(`audit/m62-packaged-2026-10-29-181758-proof.json`); dev 14/14 iz poskusa 1
(`audit/m62-dev-2026-10-29-181543-proof.json`). V obeh načinih JS in Java sledi enaki zlatemu nizu,
po reloadu enaki; `hook.signature`, `Syntax.java:3:39`, `Throw.java:5`, bus pri napakah nespremenjen.
**M6.2 sprejet.** Omejitev: zapakirani modpack potrebuje ročni `RwJavaClasspath` z Forge universal
(samodejno M6.7/M6.12); cena Java/JS ni merjena (ob integraciji).
