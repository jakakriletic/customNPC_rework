## Poskus 2 — unija pred koraki

Koda: `FlightFollow.sweep` najprej pokliče test enkrat s kvadrom
`[min(a, a + d), max(b, b + d)]` po vsaki osi (a, b = zmanjšan hitbox, d = premik do točke); prost →
`true` (števec `vidUnija`), sicer `FlightFollow.steps` = premik poskusa 1 brez sprememb.
Dokaz enakosti **[K]**: položaj koraka i je `a + d·i/n` z `0 < i/n ≤ 1`, zato je vsak korak
podmnožica unije (zaokrožitev IEEE seštevanja je monotona); `World.collidesWithAnyBlock` je
monoton v kvadru (večji kvader pregleda nadmnožico celic, `intersects` nadmnožice je resničen,
kadar je podmnožice). Prosta unija ⇒ vsi koraki prosti ⇒ isti `true`; zaprta unija ⇒ isti
koraki ⇒ isti izid. JUnit: `unijaDaIstiIzidKotKorakiNaProgahM416` (6.000 naključnih premikov po
geometriji vogala, labirinta in zida, izid unije = izid korakov), `prostaUnijaJeEnaPreverba`,
`zaprtaUnijaPreideNaKorakeInNeZavrnePreuranjeno` (NPC 0,1 v tleh).
