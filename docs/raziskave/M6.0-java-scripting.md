## 3. Pogodba izvedbe in odločitve

**Q127 — prevajalnik:** JDK 8 JavaCompiler prvi kandidat; Janino samo primerjalni prototip,
ne drugi produkcijski backend. Brez avtomatskega fallbacka med jeziki/dialekti. Prototip
mora dokazati običajen razred, generike in napačen generic tip, lambdo, notranji razred,
diagnostiko ter odsoten compiler. Primerjalni pin: `org.codehaus.janino:janino:3.1.12`
in `commons-compiler:3.1.12`; hash pridobljenih artefaktov zabeleži M6.1.
V raziskavi ni prenosa knjižnic ali spremembe `environment-lock.json`.

**Q128 — integracija:** Java veja na obstoječem handler/container robu, obstoječa izbira
`ScriptLanguage`, JS/ostali engine-i ostanejo isti. Registry je determinističen popis
hook imena → event tip/podpis, ne zamenjava EventHooks ali busa. Napačen Java hook podpis
mora dati napako, ne tiho postati »manjkajoč«. Začetni nabor API-ja uporablja obstoječe
vmesnike in evente; razširitve M7 so dodatki, ne spremembe obstoječih podpisov.

**Q129 — varnost:** M6.8 ostane obvezen kot eksplicitna trust politika, pravice in
preverjanje omejitev. Whitelist/bytecode pregled sta lahko pomoč pri napakah, nista
izolacija pred sovražno kodo; ni obljube varnega izvajanja neznanih AI izhodov. To je
že predvidena omejitev izhodnega tveganja M6, ne odstranitev meril za zanesljiv sandbox.
Java source pregleda zaupanja vredni upravljalec pred vklopom. `compileScripts` ne
inicializira/izvaja skriptnih razredov in ima annotation processing izklopljen (`-proc:none`).

**Q130 — stanje/reload/context:** skupen omejen cache bajtov, **ne** živih razredov,
instanc ali MethodHandle objektov. Ključ vsebuje izvor + urejene vključitve, compiler
verzijo/opcije in API/classpath odtis. Vsak NPC/tab/generacija dobi lasten loader in
instanco, zato niti statična polja skripte ne prehajajo med NPC-ji. Parent je game API
loader, nikoli nova kopija API razredov. Reload pripravi celotno novo generacijo handlerja
in jo zamenja med dogodki; ob neuspehu ostane zadnja veljavna generacija z vidno napako,
ob prvem neuspehu se nič ne izvaja. Ob uspehu se script polja resetirajo; eksplicitni
NPC stored/temp data ostanejo po obstoječih pravilih. Ob unloadu/reloadu odstraniti vse
naše reference na stare loaderje; ne obljubljati determinističnega GC.
`Current` zaradi binarnih porabnikov ostane; M6.6 je potreben le ob reprodukciji gnezdenega
lastništva. Takrat frame shrani/obnovi prejšnji context v `finally`; sama odstranitev
monitorja ni cilj in ne dovoljuje async game API klicev. B5 spada v M6.5 tudi brez M6.6.

z enakim številom in sledjo dogodkov, configom in okoljem; cold compile posebej, ne v MSPT.

se ovrednoti na zabeleženem korpusu, brez izmišljene številke ali naknadnega mehčanja meril.
